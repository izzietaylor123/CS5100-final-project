# CS5100 - Final Project

### Requirements
- Python 3.10, 3.11, or 3.12
- Git

### 1. Clone the repo
```bash
git clone https://github.com/izzietaylor123/CS5100-final-project.git
```

### 2. Create a virtual environment
A virtual environment keeps this project's packages separate from the rest of your computer, so everyone gets the same package versions.

**macOS / Linux**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows (PowerShell)**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Download the dataset
The dataset is too large to upload to git, so download it manually here: 
https://grfia.dlsi.ua.es/primus/packages/primusCalvoRizoAppliedSciences2018.tgz
and put it in the root.
